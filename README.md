# Experiment 4: Prompt Failure Diagnosis and Correction

## Aim
To identify common prompt failures, analyse their root causes, and improve prompts to obtain more accurate and appropriate responses from a Large Language Model.

## Problem Statement
Test three problematic prompts involving:
1. Hallucination and factual errors.
2. Instruction ignoring and format constraints.
3. Over-refusal for safe educational content.

Diagnose each failure and design a corrected prompt.

## Technologies Used
- Python
- Google Colab
- Google Gemini API
- Google Gen AI SDK

## Procedure
1. Initialize the Gemini API client securely.
2. Send each original prompt to the model.
3. Display the original responses.
4. Identify the failure type and suspected cause.
5. Send the corresponding corrected prompt.
6. Display and compare the improved responses.
7. Summarize the lessons learned.

## Expected Output
Original and corrected prompt responses, diagnoses, root causes, and a final summary.

## Result
The experiment demonstrates how prompt refinement can help reduce factual errors, improve format compliance, and obtain appropriate responses to safe educational requests.
